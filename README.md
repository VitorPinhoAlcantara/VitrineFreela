# VitrineFreela

Site de divulgação do meu trabalho como desenvolvedor freelancer.

A proposta é que quem visita já saia com uma ideia clara do que quer: dá para ver modelos de sites funcionando, conhecer os serviços oferecidos e falar comigo direto pelo WhatsApp quando decidir.

## O que tem no site

- **Serviços:** pacotes com descrição, o que está incluso, prazo e valor inicial, para o visitante comparar e escolher o que faz sentido para ele.
- **Modelos de sites:** exemplos navegáveis, cada um pensado para um tipo de negócio, que mostram na prática como o resultado final fica.
- **Contato direto:** em qualquer ponto do site, um botão leva para o WhatsApp para tirar dúvidas ou pedir um orçamento.

## Serviços oferecidos

- **Landing page:** uma página bonita e rápida no celular, que apresenta o negócio e leva o cliente até o contato.
- **Catálogo:** produtos ou serviços com foto e preço, com pedido feito pelo WhatsApp.
- **Sistemas sob medida:** como agenda online, em que o cliente marca horário sozinho e recebe lembrete.

Todos os pacotes incluem hospedagem, manutenção e pequenos ajustes mensais.

## Rodando localmente

```bash
pnpm install
pnpm dev
```
